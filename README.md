# BookHaven
***Keep your collection within reach.***

### Brief
This application is a remake of my previous [book management application](https://github.com/W0lffe/BookApp), rebuilt from the ground up using Next.js and MongoDB. The goal is to **rethink** and **improve** the <ins>existing functionality while introducing new features</ins> and a more modern structure.

### Current status of this project
The project is still in the planning and design stage.
